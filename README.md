## Features

- Native standalone edition — **no DOSBox, no emulator**
- **16:9 widescreen** with adaptive letterbox bars
- **In-game language switching** (FR / EN / DE / ZH), with separate voice and text languages
- Fullscreen by default, optional smooth (bilinear) upscaling
- Gamepad support
- Numerous crash and display fixes

## Installation (Windows)

1. Download `Versailles1685_NativeForge_Setup.exe` from the [latest release](https://github.com/nativeforge-fr/scummvm/releases/latest).
2. Run it and select your original *Versailles 1685* CD or ISO when asked.
3. Follow the steps, then launch the installed game.

Recognized original CD editions: **FR, EN, DE, ES, IT, ZH, PT-BR**.

## Why not just ScummVM?

ScummVM already runs Versailles — and, to be clear, **neither ScummVM nor this edition is an emulator**: both run the game as native code reading your original data. This is a packaged, one-click edition of that engine for people who just want to play: no setup, plus **16:9 widescreen** and **in-game language switching**, which stock ScummVM does not offer. If you prefer a cross-platform, multi-game tool, use ScummVM — the engine work is theirs.
